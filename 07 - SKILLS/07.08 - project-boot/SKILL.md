# project-boot

## When to use
A new thread about an existing project, or when the owner says "boot X" / "what's left on X".

## Steps
1. Read `BALLS.md` (workspace root) to find the project. If ambiguous, ask which one — one question, no preamble.
2. Read that project's `PROJECT.md` → objective, done, next, blocked.
3. Read `decisions.md` (why) FIRST, then `BALL.md` (state + open decisions) — the QBall resume order.
4. Restate in exactly five bullets: objective · done · next · blocked · open decisions. Every claim cites a path.
5. Ask for **the one missing decision** that unblocks progress. Nothing else.

## Rules
- Never scan chat history for project state — files are the source of truth.
- If `PROJECT.md` is missing, note it and offer to generate it from `BALL.md`.
- Flag any ball whose `updated` is older than 30 days.

## Output
Five bullets plus one question. No essay.
