# Kit — Compact

**"Compact"** is the standing one-word op: **sort & renumber the shelves so they read top-down.**

## The rules

1. **Number for a fresh reader, not for history.** A shelf's numbers should read as if designed today.
   If an item's number only makes sense because of what *used to* be there, move it. This is a
   **starter kit** — a newcomer reads the numbers cold, with no changelog.
2. **General-first.** Items baked into the **template** (what every instance needs) take the **low**
   numbers — the install kit is the model. Instance-specific items sort **later**.
3. **Folders above files.** In any listing, **folders lead**, files follow — each ordered by number.
   (Obsidian → *Files & Links* → folder-first sort.)
4. **Contiguous — everywhere.** No gaps, at **any** level:
   - **Top level:** `00, 01, 02, …` — a category number never disappears. If a shelf empties out,
     renumber what's above it to close the hole.
   - **Within a shelf:** `NN.MM` runs `01, 02, 03, …`.
   - **Count files *and* folders together.** A numbered *file* (`05.02 - x.md`) is an item; the next
     item takes the next number. Never number folders and files in two separate runs.
5. **Renumber with `git mv`** — history stays intact.

## Exempt (never renumbered)

| Item | Why |
|---|---|
| `10 - ARCHIVE` | read-only history — its `10.9x` need **not** be contiguous; the owner doesn't maintain it |
| `99 - META` | a sentinel, not a content shelf |
| `01 - PROJECTS` (`01.NN`) | the QBall registry — ids are referenced vault-wide; a finished ball keeps its number |
| `07 - SKILLS` | the numbering *is* the system/personal signal (numbered = ships; un-numbered = personal) |

## Running it

- Renumber with `git mv`; keep every reference consistent (READMEs, `index.md`, `SCHEMA.md`, crons,
  skills, scripts, filters, symlinks).
- **Check the top level first** — list `NN - SHELF` and confirm no category number is missing.
- Regenerate `index.md` (`05 - KITS/05.03 - scripts/gen-index.py`) — it lists **folders first**.
- Log the op to `log.md` and the owning ball.

> Trigger: the owner says **"compact"** (e.g. "compact 05", "compact the shelves"). Treat it as this
> SOP — deterministic, not vibes.
