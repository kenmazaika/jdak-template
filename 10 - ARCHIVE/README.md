# 10 · ARCHIVE

**Read-only history.** Superseded, completed, or rejected material. Nothing here is live —
**don't write new work into it.**

## Notes

- Retirement = *move*, don't delete: a superseded item moves here with `status: archived`,
  and a one-line tombstone is left where it lived (`SCHEMA.md` §7e).
- Legacy / pre-consolidation trees are parked here for reference.
- If something archived becomes relevant again, **promote** it — move it back to a live
  category — rather than editing it in place.
