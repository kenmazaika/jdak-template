# 03 · PERMANENT

**What we know.** The distilled, long-lived notes that outlive any single project — the
**compounding core** of the vault.

This is the top of the **capture → distill → permanent** path: raw material enters via
`00 - INBOX` / `09 - FLEETING`, gets distilled, and lands here as a durable note. A subject earns
a permanent page when it's central to a source or recurs across sources (see `SCHEMA.md` §9).

## Rules

- Every page carries frontmatter; the `kind` axis (`fact` / `opinion` / `idea`) controls
  trust and retention.
- **Facts** live forever (provenance required). **Opinions** decay (~6 months). **Ideas**
  expire in 30 days unless attached to a live goal, question, or project.
- Don't create a page for a passing mention — add to an existing page instead; split a page
  past ~200 lines.
